## 三、公司简介

深圳市国际汽车商业不动产管理有限公司深圳市属国有企业，成立于2020年4月28日，注册资本10000万元人民币，系光明投控集团有限公司全资控股企业。公司位于广东省深圳市光明区马田街道光明国际汽车城企业服务中心。

公司专注于产业空间升级，旨在重塑城市功能节点，引领产业集群发展，拥有一批专业的招商运营团队，具有丰富的汽车专业园区、商业综合体运营经验。目前公司重点开发运营一个92.5万㎡综合性汽车商业综合体——光明国际汽车城，该项目被列为深圳市重大项目，入选深圳市近零碳排放区第一批试点项目，获得了深圳市节能减排示范园区等荣誉。

项目已引入汽车品牌超过40家，吸引包括宝马、雷克萨斯、特斯拉、比亚迪、小鹏汽车等传统中高端汽车品牌及新势力汽车品牌，产生了良好的社会与经济效益，成为所在城市产业升维新样板、经济贡献增长极、城市再生示范区。

公司崇尚"以人为本、尚贤用能，德才兼备、才尽其用"的人才理念，汇聚了产业招商、运营策划、工程建设、物业管理等多个领域的专业人才，形成了一个平均年龄低于35岁、极富战斗力的年轻团队。

公司先后与中国汽车流通协会、广东省汽车流通协会、深圳汽车经销商商会、深圳二手车流通协会、光明交通运输协会等建立合作关系，积极促进政府、车企、经销商、行业协会之间的沟通联动。

## 五、核心项目：光明国际汽车城

### 5.1 项目概况

光明国际汽车城是深圳市重大项目，定位为**湾区汽车消费新中心**，是以汽车消费为核心，辅以酒店、餐饮、娱乐为一体的综合性商业园区。

| 指标             | 数值                               |
| ---------------- | ---------------------------------- |
| 总占地面积       | 92.5万平方米                       |
| 核心区建筑面积   | 27.8万平方米                       |
| 公园配套面积     | 68.4万平方米（明湖公园）           |
| 建设主体计划投资 | 5.36亿元                           |
| 主要业态         | 汽车市场、办公、酒店、公寓、商业等 |
| 引进汽车品牌     | 超50家                             |

### 5.2 项目区位与交通

项目位于光明区马田街道，周边交通发达：

- 区域内公路八纵八横，南光高速、龙大高速、外环高速通达环绕
- 1分钟即可至南光高速塘尾出入口
- 15分钟可到地铁六号线凤凰城地铁站
- 未来13号线建成通车后，距离最近的月亮路站仅5分钟车程

### 5.3 入驻品牌

已入驻品牌超过40家，涵盖传统豪华品牌、主流合资品牌及新势力品牌：

- 豪华品牌：宝马、雷克萨斯、英菲尼迪
- 新能源品牌：特斯拉、比亚迪、腾势、方程豹、小鹏汽车、理想汽车、蔚来、阿维塔
- 合资品牌：一汽丰田、一汽大众、东风日产、长安汽车
- 自主品牌：哈弗
- 其他：月子中心、餐饮（明湖楼、好光明大酒楼）等商业配套
