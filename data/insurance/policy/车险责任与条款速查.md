# 车险责任与条款速查

- 版本：V1.0
- 编制日期：2026-11-17
- 适用条款：交强险条款、机动车商业保险示范条款（2020 版）、新能源汽车商业保险示范条款（试行）
- 配套文档：《车险报价与出单操作手册》《车险承保资料汇编》（同目录）
- 使用说明：本文为条款要点速查，用于报价、承保与客户沟通，不替代条款原文；责任认定以保险合同及条款原文为准

---

## 1. 条款体系与适用

### 1.1 四类条款

| 条款 | 适用对象 | 性质 |
|---|---|---|
| 机动车交通事故责任强制保险条款 | 所有上路机动车 | 法定强制，全国统一 |
| 机动车商业保险示范条款（2020 版） | 非新能源汽车（不含摩托车、拖拉机、特种车） | 自愿投保，行业示范 |
| 新能源汽车商业保险示范条款（试行） | 新能源汽车（不含摩托车、拖拉机、特种车） | 自愿投保，专属条款 |
| 特种车、摩托车、拖拉机商业保险条款 | 对应车型 | 自愿投保，单独费率与条款 |

补充：未上牌新车短途移动，适用单程提车保险条款，不可用一年期商业险条款替代。

### 1.2 适用判定顺序

1. 先判断是否新能源汽车：是则适用新能源专属条款，不得适用 2020 版；
2. 再判断是否摩托车、拖拉机、特种车：是则适用对应车型条款；
3. 其余车辆适用 2020 版机动车商业保险示范条款；
4. 交强险独立承保，与商业险条款并行，不因商业险是否投保而改变。

### 1.3 主险与附加险关系

- 商业险分为主险与附加险，**附加险不能独立投保**；
- 主险包括机动车损失保险、机动车第三者责任保险、机动车车上人员责任保险，可全部或部分投保；
- 附加险条款与主险条款抵触的，以附加险条款为准；附加险未尽之处，以主险条款为准。

## 2. 交强险责任与条款

### 2.1 保险责任

被保险人在使用被保险机动车过程中发生交通事故，致使受害人遭受人身伤亡或财产损失，依法应由被保险人承担的损害赔偿责任，保险人在责任限额内赔偿。

- **受害人**：因被保险机动车发生交通事故遭受人身伤亡或财产损失的人，不包括本车车上人员、被保险人；
- **被保险人**：投保人及其允许的合法驾驶人；
- **赔偿原则**：分项限额、有责与无责区分，不按事故责任比例打折。

### 2.2 现行责任限额（2020-09-19 起）

| 情形 | 死亡伤残 | 医疗费用 | 财产损失 | 合计 |
|---|---|---|---|---|
| 被保险人有责任 | 18 万元 | 1.8 万元 | 0.2 万元 | 20 万元 |
| 被保险人无责任 | 1.8 万元 | 0.18 万元 | 0.01 万元 | 1.99 万元 |

提示：交强险条款文本早于 2020 年公告，条款中的限额数字已被公告调整，承保与理赔按现行限额执行。

### 2.3 各限额项下的赔偿项目

| 限额项 | 赔偿项目 |
|---|---|
| 死亡伤残 | 丧葬费、死亡补偿费、受害人亲属办理丧葬事宜支出的交通费、残疾赔偿金、残疾辅助器具费、护理费、康复费、交通费、被扶养人生活费、住宿费、误工费，以及经法院判决或调解由被保险人承担的精神损害抚慰金 |
| 医疗费用 | 医药费、诊疗费、住院费、住院伙食补助费，以及必要合理的后续治疗费、整容费、营养费 |

### 2.4 垫付与追偿

下列情形造成受害人受伤需要抢救的，保险人在医疗费用限额内垫付抢救费用，并有权向致害人追偿：

1. 驾驶人未取得驾驶资格；
2. 驾驶人醉酒；
3. 被保险机动车被盗抢期间肇事；
4. 被保险人故意制造交通事故。

除抢救费用外的其他损失和费用，保险人不负责垫付和赔偿。

### 2.5 交强险责任免除（绝对不赔）

1. 因受害人故意造成的交通事故损失；
2. 被保险人所有的财产及被保险机动车上的财产损失；
3. 受害人停业、停驶、停电、停水、停气、停产、通讯或网络中断、数据丢失、电压变化等间接损失，以及财产贬值、修理后减值损失；
4. 因交通事故产生的仲裁或诉讼费用及其他相关费用。

要点：交强险免责范围很窄，酒后驾驶、无证驾驶等情形并不免除交强险对第三者的赔付责任，只是保险人垫付抢救费用后可追偿。

### 2.6 投保人与被保险人义务

- 投保时如实告知车辆种类、厂牌型号、识别代码、号牌、使用性质、所有人信息及上年事故情况；未如实告知影响保费计算的，按保单年度重新核定保费；
- 车辆改装、加装、使用性质改变导致危险程度增加的，应及时通知并办理批改，否则按保单年度重新核定保费；
- 事故发生后及时通知保险人，协助查勘；
- 索赔需提供保单、索赔申请书、身份证明、行驶证、驾驶证、事故证明、损失清单与费用单据等。

### 2.7 合同解除条件

投保人可要求解除交强险合同的情形：车辆被依法注销登记、办理停驶、经公安机关证实丢失。解除后应交还保单与保险标志，保费按日费率计收。

## 3. 商业车险主险责任（2020 版）

### 3.1 总则关键定义

| 概念 | 条款定义要点 |
|---|---|
| 被保险机动车 | 境内行驶、以动力装置驱动或牵引的轮式车辆（含挂车）、履带式车辆及其他运载工具，不含摩托车、拖拉机、特种车 |
| 第三者 | 因被保险机动车发生意外事故遭受人身伤亡或财产损失的人，不含本车车上人员、被保险人 |
| 车上人员 | 发生意外事故瞬间在车体内或车体上的人员，包括正在上下车的人员 |
| 保费与生效 | 除另有约定外，投保人应在合同成立时一次交清保费；保费未交清前合同不生效 |

### 3.2 机动车损失保险

**保险责任**

| 情形 | 赔偿范围 |
|---|---|
| 自然灾害、意外事故 | 被保险机动车的直接损失 |
| 全车盗抢 | 被盗窃、抢劫、抢夺，经县级以上公安刑侦部门立案证明满 60 天未查明下落的全车损失；盗抢期间车辆受损的直接损失 |
| 施救费用 | 为防止或减少损失支付的必要合理施救费用，在损失赔偿金额外另行计算，最高不超过保险金额 |

**主要责任免除**

- 驾驶人交通肇事逃逸、饮酒、吸毒、服用管制精神药品或麻醉药品；
- 无驾驶证，驾驶证被扣留、暂扣、吊销、注销期间，或驾驶与准驾车型不符的机动车；
- 行驶证、号牌被注销，车辆被扣留、收缴、没收期间；
- 竞赛、测试期间，在营业性场所维修、保养、改装期间；
- 战争、军事冲突、恐怖活动、暴乱、污染、核反应、核辐射；
- 违反安全装载规定；
- 车辆被转让、改装、加装或改变使用性质导致危险程度显著增加且未及时通知，因危险程度显著增加发生事故；
- 投保人、被保险人或驾驶人故意制造保险事故；
- 自然磨损、朽蚀、腐蚀、故障、本身质量缺陷；
- 市场价格变动造成的贬值、修理后减值损失；
- 车轮单独损失、无明显碰撞痕迹的车身划痕、新增加设备损失（未投保对应附加险）；
- 非全车盗抢，仅车上零部件或附属设备被盗。

**保险金额与赔偿**

- 保险金额按投保时车辆实际价值确定，由新车购置价减折旧后协商确定，或按其他市场公允价值协商；
- 全部损失：赔款 = 保险金额 − 已从第三方获得赔偿 − 绝对免赔额；
- 部分损失：赔款 = 实际修复费用 − 已从第三方获得赔偿 − 绝对免赔额；
- 施救费按保险财产实际价值占施救财产总价值比例分摊；
- 全部损失或赔款加免赔额达到保险金额的，赔付后车损险及附加险责任终止，不退还保费。

### 3.3 机动车第三者责任保险

**保险责任**

使用被保险机动车发生意外事故，致使第三者遭受人身伤亡或财产直接损毁，依法应由被保险人承担的损害赔偿责任，对**超过交强险各分项赔偿限额的部分**负责赔偿。

**事故责任比例**

| 事故责任 | 赔偿比例 |
|---|---|
| 主要责任 | 70% |
| 同等责任 | 50% |
| 次要责任 | 30% |

自行协商或交管部门处理未确定比例的，按上表；进入司法或仲裁程序的，以生效法律文书为准。

**主要责任免除**

- 事故后故意破坏、伪造现场，毁灭证据；
- 驾驶人逃逸、酒驾、毒驾、无证、准驾不符、非被保险人允许的驾驶人；
- 车辆被扣留、收缴、没收期间，竞赛测试期间，营业性维修保养改装期间，全车被盗抢下落不明期间；
- 战争、恐怖活动、污染、核辐射；
- 第三者、被保险人或驾驶人故意制造事故、犯罪行为，或恶意串通；
- 车辆转让、改装、加装或改变使用性质导致危险程度显著增加且未及时通知；
- 停业、停驶、停电停水等间接损失，财产贬值与修理后减值；
- 被保险人及其家庭成员、驾驶人及其家庭成员所有、承租、使用、管理、运输或代管的财产损失，以及本车上财产损失；
- 被保险人、驾驶人、本车车上人员的人身伤亡；
- 停车费、保管费、扣车费、罚款、罚金或惩罚性赔款；
- 超出临床诊疗指南和国家基本医疗保险同类医疗费用标准的费用；
- 律师费，未经保险人书面同意的诉讼费、仲裁费；
- 精神损害抚慰金（可投保附加精神损害抚慰金责任险）；
- 应由交强险赔偿的损失和费用；车辆未投保交强险或交强险失效的，交强险限额内的损失商业三者险不赔。

**赔款计算**

```text
三者损失核定金额先扣除交强险分项限额，再乘以事故责任比例；
计算结果高于每次事故责任限额的，按责任限额赔付。
```

主车与挂车连接使用时视为一体，各保险人在各自责任限额内按保单载明限额比例承担赔偿。

### 3.4 机动车车上人员责任保险

**保险责任**：使用被保险机动车发生意外事故，致使车上人员遭受人身伤亡，依法应由被保险人承担的责任，按每座责任限额赔偿。

**责任限额**：驾驶人每次事故责任限额、乘客每次事故每人责任限额由投保人与保险人协商确定；乘客座位数按核定载客数（驾驶人座位除外）确定。

**主要责任免除**

- 与本车损险、三者险共通的驾驶人违法情形与车辆状态情形；
- 车辆转让、改装、加装或改变使用性质导致危险程度显著增加未通知；
- 被保险人及驾驶人以外的车上人员故意行为造成的自身伤亡；
- 车上人员因疾病、分娩、自残、斗殴、自杀、犯罪行为造成的自身伤亡；
- 罚款、罚金、惩罚性赔款；
- 超出临床诊疗指南和医保同类标准的医疗费用；
- 律师费，未经书面同意的诉讼费、仲裁费；
- 精神损害抚慰金；
- 应由交强险赔付的损失和费用。

**赔款计算**：每座损失先扣除交强险应赔金额，再乘事故责任比例，以每座责任限额为上限。

### 3.5 通用条款要点

| 事项 | 规则 |
|---|---|
| 保险期间 | 除另有约定外为一年，以保单载明起讫时间为准 |
| 出险通知 | 事故发生后 48 小时内通知保险人；全车盗抢应在 24 小时内向出险地公安刑侦部门报案并通知保险人 |
| 索赔资料 | 保单、损失清单、费用单据、行驶证、驾驶证、事故证明或法律文书、自行协商协议书；盗抢案件另需登记证书、来历凭证、立案证明 |
| 资料补正 | 保险人认为资料不完整的，应一次性通知补充 |
| 代位求偿 | 第三方造成损失的，保险人可在赔偿金额内代位行使被保险人对第三方的请求权；被保险人已从第三方获赔的，赔款相应扣减；被保险人放弃追偿权或过错致保险人无法行使的，保险人可扣减或要求返还赔款 |
| 重复保险 | 同一标的、同一利益、同一事故重复投保的，各保险人按保险金额比例承担赔偿责任，赔偿总额不超过保险价值 |
| 合同变更 | 车辆转让的，受让人承继权利义务，应及时通知并办理变更；危险程度显著变化的，保险人可调整保费或解除合同 |

## 4. 附加险责任速查

| 附加险 | 责任要点 | 投保前提 |
|---|---|---|
| 附加绝对免赔率特约条款 | 约定绝对免赔率（如 5%、10%、15%、20%），理赔时按约定扣减，保费相应降低 | 投保对应主险 |
| 附加车轮单独损失险 | 仅有车轮（轮胎、轮毂、轮毂罩）单独损坏，无其他部位损失 | 投保车损险 |
| 附加新增加设备损失险 | 出厂设备以外的新增设备（如制冷、尾板、音响）的直接损失 | 投保车损险，列明设备与金额 |
| 附加车身划痕损失险 | 无明显碰撞痕迹的车身划痕损失，按保额档次累计赔付 | 投保车损险 |
| 附加修理期间费用补偿险 | 车辆修理期间按约定天数和日限额补偿 | 投保车损险 |
| 附加发动机进水损坏除外特约条款 | 选择后发动机涉水损坏不赔，保费降低 | 投保车损险 |
| 附加车上货物责任险 | 车上货物直接损毁，依法应由被保险人承担的赔偿责任 | 投保三者险或车上人员险（按条款） |
| 附加精神损害抚慰金责任险 | 经法院判决或调解由被保险人承担的精神损害抚慰金，按限额赔偿 | 投保三者险或车上人员险 |
| 附加法定节假日限额翻倍险 | 法定节假日期间三者险责任限额翻倍 | 投保三者险 |
| 附加医保外用药责任险 | 超出医保同类标准的医保外用药费用，按限额赔偿 | 投保三者险或车上人员险 |
| 附加机动车增值服务特约条款 | 道路救援、代送检、安全检测等服务，按约定次数与范围 | 按条款约定 |
| 新能源：附加外部电网故障损失险 | 充电期间因外部电网故障导致车辆损失 | 投保新能源车损险 |
| 新能源：附加自用充电桩损失险 | 自用充电桩本身的直接损失 | 投保新能源车损险，核实权属 |
| 新能源：附加自用充电桩责任险 | 自用充电桩造成第三者人身伤亡或财产损失的责任 | 投保新能源三者险，核实权属 |

要点：附加险是"补缺口"工具，不是无限制扩展。车轮单独损失、划痕、新增设备、精神损害、医保外用药等主险不赔的项目，需通过对应附加险补充。

## 5. 新能源专属条款

### 5.1 适用规则

- 所有新保、续保的新能源汽车统一适用新能源示范条款，**不再适用 2020 版机动车商业保险示范条款**；
- 非新能源汽车不得适用新能源条款；
- 摩托车、拖拉机、特种车不适用新能源专属条款，按对应车型条款承保。

### 5.2 保险责任要点

| 险种 | 责任要点 |
|---|---|
| 新能源汽车损失保险 | 因自然灾害、意外事故（含起火燃烧）造成车身、电池及储能系统、电机及驱动系统、其他控制系统的直接损失 |
| 新能源汽车第三者责任保险 | 使用过程中致第三者人身伤亡或财产损失，依法应承担的责任；起火燃烧导致第三者损失同样在保障范围内 |
| 新能源汽车车上人员责任保险 | 车上人员人身伤亡，按每座限额赔偿 |

### 5.3 与 2020 版的主要差异

| 维度 | 2020 版 | 新能源专属条款 |
|---|---|---|
| 动力系统 | 按整车损失赔付，未单列三电 | 明确覆盖电池及储能系统、电机及驱动系统、其他控制系统 |
| 起火燃烧 | 自燃纳入车损险责任 | 起火燃烧明确列为车损险与三者险责任场景 |
| 充电场景 | 无专属附加险 | 外部电网故障、自用充电桩损失与责任险 |
| 定价 | 传统车费率 | 新能源费率，考虑车型风险分级、续航、动力性能等 |
| 电池衰减 | 不涉及 | 自然衰减、正常老化不属于意外事故责任 |

### 5.4 常见误区

1. **电池自然衰减要求理赔**：不属于意外事故，条款不赔；
2. **充电桩未投保也要求赔付**：充电桩本身损失与充电桩造成第三方损失均需对应附加险；
3. **换电车型按整车投保**：需核实电池权属，按车电分离规则处理，避免重复或漏保；
4. **家用新能源车跑网约车**：按家用费率承保的，营运期间事故可能因危险程度显著增加被拒赔。

## 6. 常见免责情形与争议点

| 情形 | 条款依据 | 结论 | 沟通提示 |
|---|---|---|---|
| 家用车跑网约车 | 车损险第九条、三者险第二十三条、车上人员险第三十四条：改变使用性质致危险程度显著增加未通知 | 因危险程度显著增加发生的事故不赔 | 按实际营运性质投保，或明确告知拒赔风险 |
| 私自改装动力、车身结构 | 同上，改装导致危险程度显著增加 | 不赔；违法改装还可拒保商业险 | 合法加装应申报并加保新增设备 |
| 车辆未年检、行驶证被注销 | 车损险第九条、三者险第二十二条 | 不赔 | 出单前核对行驶证状态 |
| 酒驾、毒驾 | 各主险责任免除 | 商业险不赔；交强险仍赔第三者，垫付抢救费后可追偿 | 不得以任何方式承诺赔付 |
| 无证驾驶、准驾不符 | 各主险责任免除 | 商业险不赔；交强险垫付抢救费后追偿 | 核保时核对驾驶证 |
| 肇事逃逸 | 各主险责任免除 | 商业险不赔 | 提示法律后果 |
| 故意制造事故 | 各主险责任免除 | 不赔，可能涉及保险欺诈 | 移交反欺诈处理 |
| 竞赛、测试、营业性维修保养改装期间 | 各主险责任免除 | 不赔 | 试驾车、赛道活动需专门方案 |
| 车轮单独损坏、无明显痕迹划痕 | 车损险第十一条 | 主险不赔，需附加险 | 报价时主动推荐对应附加险 |
| 车辆贬值、修理后减值 | 车损险第十一条、三者险第二十四条 | 不赔 | 不属于直接损失 |
| 停业停驶等间接损失 | 三者险第二十四条 | 不赔 | 营运车建议补充停运损失类保障（如有产品） |
| 医保外用药 | 三者险、车上人员险责任免除 | 主险不赔，需附加医保外用药责任险 | 报价时说明 |
| 精神损害抚慰金 | 三者险、车上人员险责任免除 | 主险不赔，需附加精神损害抚慰金责任险 | 人伤案件高发场景建议附加 |
| 本车人员伤亡向三者险索赔 | 三者险定义与免责 | 不赔，应由车上人员责任险承担 | 区分三者险与座位险 |
| 未投保交强险 | 三者险第二十四条 | 交强险限额内损失商业三者险不赔 | 交强险必保，不得脱保 |
| 非被保险人允许的驾驶人 | 三者险、车上人员险责任免除 | 不赔 | 家庭用车建议列明常用驾驶人 |

## 7. 赔偿处理规则

### 7.1 赔付顺序

```text
第一步：交强险在各分项限额内全额赔付（不分事故责任比例）；
第二步：交强险不足部分，由商业三者险按事故责任比例、在责任限额内赔付；
第三步：仍有不足的，由侵权人自行承担。
车损险、车上人员险按各自条款与责任比例单独计算，不适用交强险先行赔付规则。
```

### 7.2 关键计算公式

```text
车损险全损：赔款 = 保险金额 − 第三方已赔金额 − 绝对免赔额
车损险部分损失：赔款 = 实际修复费用 − 第三方已赔金额 − 绝对免赔额
三者险：赔款 =（核定三者损失 − 交强险分项限额）× 事故责任比例，以责任限额为上限
车上人员险：赔款 =（每座核定损失 − 交强险应赔金额）× 事故责任比例，以每座限额为上限
```

### 7.3 代位求偿

第三方造成车辆损失的，被保险人可直接向保险人索赔，保险人先行赔付后在赔偿金额内代位向第三方追偿。被保险人已从第三方获赔的部分，保险赔款相应扣减；被保险人放弃追偿权或重大过失致保险人无法追偿的，保险人可扣减或要求返还赔款。

### 7.4 重复保险

同一车辆、同一保险利益、同一保险事故重复投保的，各保险人按保险金额比例分摊赔偿，赔偿总额不超过保险价值。交强险同一车辆同一期间只能有一份有效保单。

### 7.5 索赔时限与资料

| 项目 | 要求 |
|---|---|
| 一般事故通知 | 48 小时内 |
| 全车盗抢报案 | 24 小时内向公安刑侦部门报案并通知保险人 |
| 索赔资料 | 保单、损失清单、费用单据、行驶证、驾驶证、事故证明或法律文书、协商协议书 |
| 资料补正 | 保险人一次性告知 |
| 核定与赔付 | 按保险法规定的时限核定，达成赔偿协议后按约定支付 |

## 8. 条款使用与版本管理

1. **版本对齐**：报价、录单、核保、理赔引用同一版本条款，保单载明条款名称与版本；
2. **新能源优先判定**：先判能源类型，再选条款，避免套用错误条款；
3. **免责说明留痕**：免责条款须提示并明确说明，投保提示书手书确认或电子点选确认；
4. **属地差异**：附加险种类、费率方案、特别约定以属地监管与公司报备为准；
5. **条款变更**：监管或行业发布新版本后，系统条款库、报价模板、话术同步更新，旧版本保单按原条款执行；
6. **原文核对**：对外答复、投诉处理、诉讼应诉时，以条款原文为准，速查表仅作内部参考。

## 9. 术语表

| 术语 | 含义 |
|---|---|
| 责任限额 | 保险人对每次事故承担赔偿的最高金额，交强险分死亡伤残、医疗费用、财产损失三项 |
| 保险金额 | 车损险项下保险标的的投保金额，按投保时实际价值确定 |
| 绝对免赔额/免赔率 | 理赔时由被保险人自行承担的固定金额或比例，可通过附加险约定 |
| 事故责任比例 | 被保险机动车一方在事故中的责任对应的赔偿比例，主责 70%、同责 50%、次责 30% |
| 代位求偿 | 保险人赔付后，在赔偿金额内取得向第三方追偿的权利 |
| 重复保险 | 同一标的、同一利益、同一事故向多家保险公司投保 |
| 车上人员 | 事故瞬间在车体内或车体上的人员，包括正在上下车的人员 |
| 第三者 | 除本车车上人员与被保险人以外的受害人 |
