# SPC-003 用户对话持久化与记忆管理

## 背景
当前系统的对话历史存储在 LangGraph 的内存 Checkpointer 中，进程重启即丢失，且无长期记忆能力。需要将用户对话持久化到 Markdown 文件，并通过摘要 + 滑动窗口管理上下文，支持长对话。

## 需求

### 1. 对话持久化
- 用户每轮对话（用户提问 + 助手回复）保存为 Markdown 文件
- 存储路径：按用户隔离，如 `data/conversations/{user_id}/{thread_id}.md`
- 保存内容：时间戳、用户消息、助手回复（含工具调用信息可选）
- 同一 thread_id 追加写入，不覆盖
- 支持按 user_id 列出历史会话列表，按时间倒序

### 2. 摘要 + 滑动窗口记忆
- 当对话轮次超过 3 轮时，对最早的对话进行摘要压缩
- 滑动窗口：始终保留最近 3 轮对话作为即时上下文
- 更早的对话由摘要替代，注入到系统提示中
- 摘要由 LLM 生成，覆盖已滑出窗口的历史信息
- 摘要随新轮次滑出而增量更新，不重复计算全部历史

### 3. 与 Agent 集成
- 对话开始时加载该 thread 的历史：摘要 + 最近 3 轮
- 对话结束后：保存本轮到 md、更新摘要、裁剪窗口
- 摘要与窗口作为 Agent 的输入上下文

## 验收标准
- 用户对话后，对应 md 文件被创建/追加，内容完整
- 重启后端后，同一 thread 的历史可从 md 恢复
- 对话超过 3 轮后，最早轮次被摘要替代，上下文保持可控长度
- 历史会话列表可按 user_id 查询
- 前端可查看历史会话列表并切换
